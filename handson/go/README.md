# Awesome Pizza API (Go)

Go port of the `jsts` API, using only the standard library (`net/http`, Go 1.22+ routing).

## Run

```bash
go run .
```

The server starts on port `3000` (override with the `PORT` environment variable) and exposes the same endpoints as the other backends. See [docs/openapi.yaml](docs/openapi.yaml) for the full API contract.
